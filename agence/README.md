# L'agence Croc Parc — mode d'emploi

**Qui** : Jonathan (pilote) + 6 agents Claude spécialisés + l'équipe du parc (Julien, Babeth, Brice, Florence).

## Les 6 agents (`.claude/agents/`)
| Agent | Spécialité |
|---|---|
| **studio-creation** | Identité visuelle, logo, charte, signalétique, carte, affiches |
| **social-media** | Instagram/Facebook, reels, drone, boosts, influenceurs |
| **evenementiel** | Salons, animations UNESCO, mariages, Gramoun, scène, mairie, ERP |
| **digital-growth** | Site, SEO/GEO, billetterie, newsletter, CRM, RGPD |
| **veille-marche** | Études, données sourcées, concurrence, subventions |
| **plume** | Emails, courriers officiels, dossiers, scripts d'appel |

## La mémoire
- **Globale** : `MEMOIRE.md` (état des lieux vivant) + `journal/` (une entrée par session)
- **Par agent** : `memoires-agents/<agent>.md` (chaque agent lit la mémoire globale + la sienne avant de travailler, et les met à jour après)
- **Références** : `references/` (compte-rendu fondateur, études marché…)

## Les règles
Voir `REGLES.md` — les non-négociables : **jamais d'envoi sans relecture**, livrables **concis/gras/visuels**, **aucun chiffre inventé**, mise à jour de la mémoire à chaque session.
